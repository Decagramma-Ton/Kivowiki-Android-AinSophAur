## 当前边界

1. 组织及关系公开资料已交付；组织表态／老师补充互动、漫画、配队、留声机等整站模块未在本次扩展。没有自行添加养成公式或无契约的大厅台词互动。
2. 代表性样本覆盖不等于全站所有模型／骨架与所有手机兼容；超出版本、资源或内存预算明确提示。真机 GPU、厂商系统与性能矩阵仍需扩展。
3. Mermaid 已采用本地引擎渲染；LaTeX 和部分 HTML 视觉样式保留既有可读降级；超预算长文完整保留原文，不静默截断。
4. 本轮未用生产账号测试表态和补充写入。使用本地替身检查认证、null 成功信封、过期和结果不确定时不重试；此前 F1 的真实账号验证不重复记作本轮通过。
5. 正式私钥、发行渠道、App Links 尚未配置；Spine 运行时使用许可需站方在公开分发前核对。站内素材许可与运行时许可分别记录。
6. 本项目是由社区独立维护的非官方第三方客户端，不代表站方立场，也不经官方渠道发布。
