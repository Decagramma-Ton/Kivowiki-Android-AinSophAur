## 后续容易踩到的边界

1. 姓名搜索同时发送 name 和 character_data_search；只发后者在本次线上返回未筛选的全部学生。枚举大小写和 false 必须保留。
2. 346 的“终演的旋律” max_level=10，但实际只有 5 条说明；不能编造其余等级。619、593 的模板零值和占位年龄不是可信战斗资料。
3. Navigation 3 entry 内创建带依赖的 ViewModel 必须使用宿主 Hilt 工厂。换装替换当前角色项并保留分类；普通关联跳转压栈。
4. Spine Canvas 必须裁剪自己的视口，否则背景会盖住工具栏。Filament 由 ModelViewer 的 detach listener 销毁 engine，禁止再次销毁。
5. 媒体需要用户点按才下载；Atlas 按页名匹配；4.2 之外明确提示。暂停与后台停止帧回调，动态素材不能混入普通列表中持续渲染。
6. 表态与补充测试只访问本地替身。LiveAccountAcceptanceTest 未显式给专用账号时跳过；不记录口令、令牌和私有正文。
7. 测试 UI 截图须等待键盘和弹窗退出，避免把输入法浮窗当作 App 界面。设备脚本只操作 Kivo_Archive_Phone，并在 finally 恢复临时设置。
8. ON_STOP 必须直接暂停原生 View，不能仅改变 Compose State 等待重组；后台重组可能已经暂停。GIF 与 Spine／3D 都执行这一规则。
9. 超长文档、非 4.2 骨架、稀疏嘴部数据与超预算资源都有明确边界。不要为了消除提示而扩大无界内存、解析或下载。
10. 深链接处理时同步设置 startupApplied。否则链接先于 DataStore 被消费，稍后加载的非首页启动偏好会覆盖目标页面。Release 检查包括图鉴启动偏好下的角色冷启动链接。
