# ADR-023：五栏导航、全站搜索与权限阅读

状态：已实施；日期：2026-09-07；版本：0.2.0。

站长要求让角色图鉴拥有直接入口，同时保留资料和典藏分类，并能选择启动位置。采用五个独立根返回栈；中心图鉴按钮在同一底栏中轻微上提，保留统一触控和可访问性语义。启动目标存为枚举名，只在全新启动时应用，系统任务恢复优先保留阅读上下文。

全站搜索使用网站实际搜索接口，不用逐项扫描全部百科来拼接结果。输入防抖并取消旧协程；查询与结果仅存在当前页面。网站的相关度自动跳转容易把宽泛词导向特定换装，App 只在用户确认、完整单页结果中唯一精确匹配时跳转，事件不重放。

私有文章通过 AccountRepository 显式认证端点读取；公共 ContentRepository 不持有账号令牌，也不缓存认证正文。访问令牌刷新、读取与退出由同一会话锁串行处理；页面订阅账号身份变化。私有正文不写入历史、收藏或系统任务截图。真实测试账号仅由测试运行时参数传入，普通套件跳过真实账号测试。

社区名单与联系页来自已核实的公开前端快照，原生展示来源日期；QQ 频道是明确限定用途的内置浏览器，不导入百科登录态。未来若提供稳定社区 API，再以 Repository 和 DTO 替换快照。

详细行为、兼容范围和网站差异见 [实施同步](../../../App项目文档/19-系统体验迭代实施同步.md)。
