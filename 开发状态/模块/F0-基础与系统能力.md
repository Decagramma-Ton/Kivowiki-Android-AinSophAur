# F0 · 基础与系统能力

需求来源：站长 2026-09-06 本次开发指令，以及睡前“后续不追问，涉及风险的跳过并说明”的补充。状态：已实现，自动检查和电脑验收证据见验收报告，用户验收待进行。

## 用户结果

在电脑打开真正运行的安卓 App，随后可复制一个普通 APK 到手机手动安装。用户能够浏览真实首页、切换服别、阅读公告与近期文章、收藏、查看本机足迹、进入账号页及修改设置。未开展的完整业务模块有清楚的阶段说明与网站入口。

## 验收条件与实际边界

- Release APK 可在专用 Android 模拟器安装、冷启动和操作，包名与 Debug 独立。
- 首页使用匿名公开 API；每块保留独立加载、空内容、失败和缓存状态；失效日程不伪装成当前日程。
- 原生公告阅读 → 收藏 → 我的 → 再次打开可运行；已缓存的公告在模拟器断网后仍可阅读。
- 主题保存、页面重建、根标签滚动恢复、大屏和系统 200% 字号有自动/视觉证据。
- 会话安全分支通过本地替身与真实 Keystore 测试；未用真实账号验证服务器成功返回，不能算生产登录验收完成。
- 真机、低端设备、旧 Android、多厂商安装与性能，仍由下一轮真实设备验收补证。

本模块不改变服务器数据。未知或需账号持有人参与的事项写入交接，没有通过猜测接口或伪造登录绕过。
