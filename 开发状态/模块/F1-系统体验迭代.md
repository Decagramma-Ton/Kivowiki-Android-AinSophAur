# F1 系统体验迭代规格

实施版本：0.2.0。

本轮在 F0 根基上交付用户明确提出的首页顺序、五栏导航、启动目标、扩展 Markdown、角色副标题、文案、品牌素材、社区入口、项目仓库入口和体验优化，同时接入全站搜索与网站已有设置。

验收路径：

1. 首页古书馆资讯 → 近期编辑 → 本周生日 → 日程，原皮不显示占位副标题，资讯与文章仍可阅读。
2. 中置图鉴进入真实角色列表，资料入口指向同一根页面；五根切换保留位置。
3. 设置选择图鉴，完全关闭进程再启动，底栏选中图鉴；恢复已有后台任务保留原页面。
4. 国服译名回退、逐级技能默认等级、自动跳转开关、减少动效等保持持久化。
5. 全站搜索输入、确认、清空、分页、返回和网络失败；多义词不误跳。
6. 提示块、代码示例、标签页、对齐、嵌套 details 和图片尺寸写法按原生规则读取。
7. 真实账号登录、授权文章、会话恢复与退出；权限正文不落公共缓存。
8. 我的新增贡献者、帮助与 QQ 频道；按钮可打开、返回，QQ 唤起留真机手测。
9. 浅深色、200% 字号、平板、离线、R8 Release 覆盖安装验证。

具体取舍、延后范围及文档同步见 [19](../../../App项目文档/19-系统体验迭代实施同步.md)，检查结果见 [验收报告](../../artifacts/验收报告.md)。
