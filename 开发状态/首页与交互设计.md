# 首页与交互设计

## 设计依据

已现场检查 `https://kivo.wiki/` 首页及登录页，读取与本期有关的公开接口、网页资源与既有文档。网页首页的信息较多，直接平移到手机会造成长篇公告挤占日程、资讯与角色入口。0.2.0 按站长最终反馈调整为“古书馆资讯 → 近期编辑 → 本周生日 → 当前日程 → 站内动态”，让时效性最强的新闻横幅成为欢迎语后的第一块内容。

## 首页信息取舍

| 内容 | 首页展示量 | 进一步操作与原因 |
| --- | --- | --- |
| 新闻横幅 | 最新 6 条，手动翻页，不自动轮播 | 点击原生阅读，更多资讯打开当批列表；推广保留广告标记，不增加独立广告 SDK |
| 常用入口 | 首页已移除 | 功能统一由底部资料、图鉴、典藏入口承接 |
| 当前日程 | 日服、国服；卡池、活动、总力战各一行 | 首页优先日期、状态和卡池学生名；横幅及学生明细放在底部详情面板，减少三张大图的重复占位 |
| 国际服 | 显示接口尚未接入 | 不用日服数据冒充国际服，不推算未经证实的活动 |
| 最新公告 | 单行入口 | 独立公告列表分页与原生正文，避免长公告占满首页 |
| 近期文章 | 3 条，后台当批取 4 条 | 标题、摘要、封面；报刊亭完整模块后续接入 |
| 最近编辑角色 | 6 名，水平列表 | 头像、名称和换装；点击资料速览，不伪称完整档案 |
| 今日幸运物 | 1 项 | 兼容 item / equipment / student；异种或缺失数据保留明确提示 |
| 本周生日 | 接口返回去重后最多 24 个 ID | 水平展示，单个角色失败不使整个首页失败；可在设置关闭 |
| 那年今日 | 近 5 年、每年最多 5 条，首页先显示 3 条 | “更多回忆”显示本次选读；日期使用北京时间；不扫描全史书 |

日程使用服务端秒时间与单调时钟计算。日服时间标为 UTC+9，国服时间标为 UTC+8；倒计时所用绝对时刻不受手机调整时区影响。区间缺失或结束时间早于开始时间显示“资料待更新”；已经结束显示“已结束 · 待更新”。缓存及获取时间始终可识别，错误不会替换成“没有内容”。

首页前台每分钟更新时钟并按 TTL 检查日程；跨天刷新与日期有关的数据。进入后台后停止这个循环，不运行后台定时服务。

## 视觉与布局

- 主色是偏青的古书馆蓝，浅色底为轻微冷白，深色使用深蓝灰；正文与弱化文字分别定义语义色。
- 顶栏采用用户提供的 KivoWiki LOGO 矢量，空搜索页使用 Q 版素材；其他光环与 K 图形使用矢量绘制，图片主体来自站点按需加载，不打包大型背景、字体或角色素材。
- 系统中文字体优先保证可读性、缺字兼容和包体；不下载全站字体。阅读字号只调整正文，并尊重系统字体缩放。
- 卡片用于有独立操作或状态的内容；文章列表使用分隔线，避免所有内容都变成大块卡片。
- 手机底部五个根入口：首页、资料、中置图鉴、典藏、我的；详情页收起底栏，以明确的返回按钮及系统返回手势导航。
- 宽度达到 840 dp 使用侧边导航。首页内容区域达到 1000 dp 时分为主阅读栏与日程/幸运物侧栏；阅读正文限制最大 720 dp。
- 根标签保存各自返回栈及滚动位置。页面可重建，重要个人状态存储于本机数据库；密码在重建时清空。
- 图片不自动播放、新闻不自动翻页；普通转场较短，“减少动效”关闭导航淡入和程序触发的平滑滚动。

## 本期阅读器的边界

采用 CommonMark AST 转原生内容块，覆盖标题、段落、强调、链接、列表、引用、代码、表格、图片及嵌套 details。脚本、表单、iframe 等不执行；未知 HTML 尽量保留可读文字。

这不代表站点所有 Markdown 方言均已还原。角色技能表、复杂嵌套排版、媒体、双栏 HTML 和超长图仍由后续富文本/媒体模块扩展。正文图片预览支持 1–4 倍缩放，当前按屏幕需要解码，放大不是无损原尺寸或分块解码。

本地收藏保存实体身份和摘要，正文属于可清理缓存。已经缓存的正文可离线打开；“收藏”不等于永久下载全文。
