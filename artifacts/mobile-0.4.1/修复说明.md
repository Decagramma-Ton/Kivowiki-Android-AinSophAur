# 0.4.1 手机体验修复

日期：2026-09-07。版本：0.4.1 / code 5。安装包使用现有 preview 包名与本地验收签名。

## 对应本轮十项问题

| 问题 | 实现 |
| --- | --- |
| 图鉴过疏 | 卡片最小宽度 88dp，随字体缩放调整列数；普通手机可显示 3～4 列。移除卡片组织名，保留正方形头像及两行姓名空间。紧凑列表保持可选。 |
| 资料底部滚动卡住 | 关系加载状态按实体保留；补充资料、表态状态由 ViewModel 持有，避免 LazyColumn 回收条目时重新出现矮加载占位、反复改变滚动高度。居中长文拆成保持对齐的阅读条目。 |
| 基本信息太长 | 稀有度／身高／生日三列，中日配音两列；按可用宽度与字体比例判断，窄屏自动回到单列。 |
| 分类横滑突变 | 使用真正的 HorizontalPager，页面与指示线跟随手指，可停在两页之间；分别保留阅读位置。点击跨页不会等待尚未布局的列表而卡死。离开语音页立即暂停播放。 |
| 图片与网络 | 图片独立并发配额，失败后有限退避重试，最终提供手动重试。系统网络恢复后通知可见失败内容重试。公开读取允许连接恢复，账号写入仍禁止不确定结果的自动重放。媒体按单文件重试，保留已下载成功的资源，不因某个文件失败重下整包。 |
| 完整导出 | 默认从独立完整画布导出，Spine 按骨架内容及录像期间边界取景；模型按世界空间几何及附件边界取景。用户预览缩放不会裁掉完整导出。可切换当前画面。 |
| 设置不易发现 | 设置区顶部固定显示“动作 · 画面 · 导出”和“更多设置↓”，点击直达底部；宽屏保留侧栏。 |
| 复杂 Markdown | 使用官网妃咲 61、圣三一 2 的实际资料建立固定回归样本；支持带嵌套链接的图片标题、行内徽章、未闭合至文末的对齐容器及通知标题中的 font 标签。 |
| 图片文件名干扰 | alt 保留为无障碍描述，不再作为正文图注显示；只有作者明确提供的标题图注才可见。 |
| 图片尺寸失效 | 图片宽高元数据随每个 Markdown 节点保留，相同 URL 的不同尺寸不会互相覆盖；独立图片保持实际长宽比，并受屏幕宽度约束；小徽章留在文本原位置。 |

## 导出规格与边界

- PNG 为重新渲染的完整画面，不是把手机截图放大。Spine 默认最长边上限 4096；模型默认 2048×2048。源纹理本身的清晰度决定最终细节。
- MP4 提供 5／10 秒、24fps、720／1080／1920 最长边选项。根据设备 AVC 编码能力对齐尺寸并降档，完成提示展示实际输出尺寸。录像不带声音。
- 离屏录像独立采样动画，不改用户预览镜头；模型会话复用 GPU 对象与像素缓冲。取消、离开前台会结束任务并清理临时输出。
- 网络重试有上限，404、不可重试的服务响应与资源预算错误不会无限重试；离线仍展示已缓存资料。无法保证站点或运营商故障时所有资源都能成功加载。
- 已验证的四类媒体样本不等于全站所有骨架、模型或所有厂商 GPU 已覆盖。真机兼容性和持续性能仍需在用户手机复测。

## 验证入口

完整单元检查、Debug／Release Lint 与发行构建：`tools/build.ps1 -Target Verify`。

设备回归：`tools/mobile-acceptance.ps1`。脚本只操作本项目的 Kivo_Archive_Phone / emulator-5558，包含普通手机、320dp 窄屏与 200% 字体，并在 finally 恢复设备设置。测试使用公开资料与本地文件，不写入生产互动数据。

设备日志、导出样本与截图保存在本目录；最终结果见 `验证结果.md`。旧版本报告与 APK 摘要不适用于本版。

## 真机重点复测

1. 图鉴默认字体与大字体；妃咲资料到底后连续小幅回滑；圣三一居中段落与奖项图片。
2. 角色分类按住半程、松手、连续快滑，语音页离开后停止播放。
3. Wi-Fi 与移动网络切换、临时断网恢复，观察图片与媒体重试。
4. Spine 立绘／大厅、人物模型／光环导出完整 PNG 与 10 秒最高档视频，检查边界、方向、编码兼容性及耗时。
