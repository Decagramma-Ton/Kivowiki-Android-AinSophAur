设备：专用 Android 16 / API 36.1 模拟器，1080 × 2400。没有操作真实手机、生产账号或服务器写入接口；测试所改偏好在结束时恢复。本轮没有重跑全站素材矩阵、全部旧 UI 用例或厂商真机 GPU 测试。

设置 UI 测试初次迭代遇到两个测试驱动问题：尚未组合的惰性列表节点不能直接 `performScrollTo`，改由列表搜索滚动；深链改变 Activity Intent 后，须恢复原 Intent，才能由 ActivityScenario 正常结束。最终保存的 XML 均为修正驱动后通过的结果，未隐藏产品断言失败。
